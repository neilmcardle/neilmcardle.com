# State machines on neilmcardle.com

Every lifecycle that used to be spread across booleans, status strings and timers is written down once, as a typed union of states and one pure transition function. Each machine lives in a small file next to the component that uses it, with a Vitest file beside it. Run them all with `npx vitest run`.

Read the machine before adding a flag. If a new flag only makes sense alongside another one, add a state or an event instead.

makeEbook keeps its own map in [`app/make-ebook/STATE.md`](../app/make-ebook/STATE.md).

## The pattern

- **States are a union.** A request is never loading and failed at once, because no state has both.
- **One transition function.** `transition(state, event)` returns the next state, or the same state when the move isn't allowed. Late or stale events (an old run, a closed cover, a reset game) fall through as no-ops.
- **useReducer drives it.** Components derive the older flag names from the state, so markup doesn't change.
- **Timers belong to the state that starts them.** An effect keyed to the state sets the timer and its cleanup clears it, so leaving the state or unmounting cancels it. Requests carry a run number or an AbortController for the same reason.
- **No library.** The tables are small enough that plain TypeScript is clearer than a framework.

## Small flows kept as flags

These are short enough that a ref is clearer than a reducer.

- **Vector Paint order sheet:** `submitting` resets on `pageshow` after Back from Stripe; ordering from the Wall closes the Wall first.
- **Spark waitlist:** a ref blocks a second send while one is in flight.
- **Writing contents:** the scroll lock owns its `scrollend` listener and removes it on the next click and on unmount.
- **Homepage stack:** keyboard use (Tab or arrows) clears the touch flag, so focus opens cards again after a tap.
- **NavMark:** particles that finish loading after the pointer has left stay hidden.
- **Coverly filters:** the spinner key only shows while its transition is pending, and the search box follows the URL on Back and Forward.
- **Coverly:** the heart and like pulse timers clear on unmount; the board PDF's object URL is revoked a second after the download starts.
