# Neovim Resources

## Knowledge

- [vimtutor (built-in)](https://neovim.io/doc/user/usr_01.html#vimtutor)
  The official interactive tutorial. Type `vimtutor` in the terminal. 30 minutes. The single best first-contact resource — teaches by doing, inside vim itself.

- [Neovim official documentation](https://neovim.io/doc/user/)
  Authoritative reference for everything. Reach for this when in doubt about behaviour. `:help <topic>` inside nvim opens it inline.

- [Book: _Practical Vim_ — Drew Neil (Pragmatic Programmers)](https://pragprog.com/titles/dnvim2/practical-vim-second-edition/)
  The gold standard book. Teaches the vim way of thinking — not memorising commands but understanding the composable grammar. Reach for this once basic navigation is comfortable.

- [Neovim from Scratch — TJ DeVries (YouTube playlist)](https://www.youtube.com/playlist?list=PLhoH5vyxr6Qq41NFL4GvhFp-WLd5xzIzZ)
  TJ is a core nvim contributor. This series builds a config from scratch in Lua. Use for: understanding nvim config structure and plugin ecosystem.

- [ThePrimeagen's Neovim videos (YouTube)](https://www.youtube.com/@ThePrimeagen)
  High-energy, practical. Useful for picking up workflow patterns and motions from an expert in real use. Less structured than TJ — good as supplementary viewing.

## Wisdom (Communities)

- [r/neovim](https://reddit.com/r/neovim)
  Active, well-moderated. Good for: plugin recommendations, config troubleshooting, "is this the right way to do X" questions.

- [Neovim GitHub Discussions](https://github.com/neovim/neovim/discussions)
  For questions closer to core behaviour, bugs, or feature rationale.
