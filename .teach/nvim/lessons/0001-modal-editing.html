Modal Editing

The one idea that makes everything else in nvim click.

The big idea

In VS Code, your keyboard does one thing: type text. Every shortcut is ⌘ + something, because the letter keys are reserved for typing.

nvim works differently. It has modes. In different modes, the same keys do completely different things. This sounds strange at first, but it's the reason nvim users can edit code so fast — the most common actions (move, delete, change, copy) live on the home row, not behind modifier keys.

The mental shift

You are not always typing. When you're not typing, every key on the keyboard is a command. This is modal editing.

The two modes you need right now

Normal Navigate & command
⇄ i / Esc
Insert Type text

Normal mode is the default. When nvim opens, you are in Normal mode. Keys here are commands — they move, delete, copy, and change things. This is where you spend most of your time.

Insert mode is where you type. It works like any other editor — keys produce characters. You enter it deliberately, do your typing, then leave.

The key insight: nvim assumes you are reading and navigating more often than you are typing. Normal mode is the default because navigation is the default activity.

Switching between modes

Key What it does
i
Normal → Insert. Start typing before the cursor.
The most common way to enter Insert mode.
Esc
Insert → Normal. Stop typing, go back to command mode.
You will press this constantly. Muscle memory builds fast.

Moving around (Normal mode)

In Normal mode, four keys move the cursor. They sit on the home row under your right hand:

Key Direction
h
Left
j
Down
k
Up
l
Right

Arrow keys also work, but hjkl keep your hands on the home row. Don't force it — just be aware they exist. The habit builds over time.

Saving and quitting

These are typed as commands starting with : in Normal mode. The colon opens a command prompt at the bottom of the screen.

Command What it does
:w Enter
Write (save) the file
:q Enter
Quit (only works if no unsaved changes)
:wq Enter
Write and quit
:q! Enter
Quit and discard changes (the panic escape)
Try it now

Open your terminal and run nvim test.txt. You're in Normal mode. Press i — notice the bottom of the screen shows -- INSERT --. Type something. Press Esc. The indicator disappears — you're back in Normal mode. Type :wq and press Enter to save and quit.
