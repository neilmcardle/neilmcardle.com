    UI Taste

    141 interface decisions, each with a live demo, the exact values and what it costs in speed. Pick which system you are choosing for, set each item the way you want it, then press Use this or Leave out. Your choices stay in this browser. When you are done, download them and give the file to your coding agent.

    I used it to make Performance UI and Looks UI. Made by Neil McArdle.

    Performance UI is for sites where speed matters most: booking flows, shops, news, anything used on slow phones and patchy signal. Every choice should cost little or nothing in load time or smoothness. Its rules are tagged Foundation or Style. On a page that already has a brand, only the Foundation rules apply.

    Looks UI is for sites where the impression matters most: portfolios, launches, brand pages. Anything that makes it look and feel better is allowed, as long as it still works for everyone. Some speed cost is fine.
